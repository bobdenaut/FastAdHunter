How this page saves

The API takes lines in and gives lines out — there is no per-rule identity behind it, so this is a document, not a table. That is why there is no per-rule delete button and no per-rule enable toggle: they would promise a write the API cannot perform. Save is all-or-nothing. Every line is validated, then the whole set is swapped atomically. One bad line means nothing is written — never a partial save. A successful save applies immediately. No restart, no recompile of the lists.
