What costs what

RECOMPILES seconds of CPU on the RB5009

Creating a policy, changing which lists it holds, deleting one. Per-rule policy masks are built at compile time over 752,585 rules, so the whole ruleset is rebuilt and swapped. The UI asks before doing any of these.

LIVE milliseconds

Renaming a policy, and assigning or unassigning a client. Assignments change no mask, so they apply at once and need no warning.

One assignment per address — assigning a client already covered elsewhere replaces that assignment, in whichever policy held it. A shut schedule window is not "no policy": the client falls back to whatever else covers it, a subnet assignment or default.
