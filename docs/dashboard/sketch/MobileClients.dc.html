A solid chip is an assignment naming this address. A dashed chip is inherited — from a subnet, a name, or the default policy — and the API says which, so the card never has to guess. Clients are observed by traffic. A device that has never asked anything does not appear here: there is no ARP table and no DHCP lease list behind this page.
Tapping a card expands its actions rather than opening a separate screen — rename and change-policy are the only two, and both are one round trip. A phone reaching this page is usually answering one question: why is that device blocked, and can it stop.
