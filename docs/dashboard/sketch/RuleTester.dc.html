Two questions this answers

“Why is this blocked for the TV?”

Test as the client. The engine picks whatever policy is in force for that address at this moment, so the answer accounts for schedules — including a window that just closed.

“What would the kids policy do?”

Test under a policy instead. Assignments are ignored and the named policy decides, so you can check a policy before anything is assigned to it.

This runs the compiled ruleset — the same code path a real query takes — so it cannot drift from what clients actually get. It answers the verdict only: nothing is resolved, no upstream is contacted, and nothing is cached.
