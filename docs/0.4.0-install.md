# 0.4.0 on bobdenaut — install steps

Router read 2026-09-19. Everything not listed here is already in place.
Dev box commands are PowerShell. Router commands go into the `ssh bobdenaut` console.
Run the chapters in order.

## 1. Build the image (dev box)

The tar on the dev box is older than the 0.4.0 code. Rebuild it.

```powershell
git checkout v0.4.0
docker buildx build --platform linux/arm64 -t fastadhunter:0.4.0 -o type=docker,dest=fastadhunter-arm64-0.4.0.tar .
```

## 2. Upload the image (dev box, then router)

The router has no 0.4.0 tar.

```powershell
scp fastadhunter-arm64-0.4.0.tar bobdenaut:kingston/
```

```routeros
/file/print where name~"0.4.0"
```

Expect one `.tar file` of about 16 MiB.

## 3. Back up the config and put the new one in place (dev box)

The new TOML turns on `dns+http+https`, DoT, DoH and the 8444 listener. It must be
in place before the container starts.

```powershell
$toml = ssh bobdenaut ':put [/file/get kingston/fastadhunter/config/fastadhunter.toml contents]' | ForEach-Object { $_.TrimEnd("`r") }
[IO.File]::WriteAllText("$PWD\fastadhunter.toml.0.3.4", ($toml -join "`n"))
scp docs/fastadhunter.toml bobdenaut:kingston/fastadhunter/config/fastadhunter.toml
```

## 4. Add the container (router)

0.3.4 keeps serving while the tar extracts. `start-on-boot=no` for now so a reboot
cannot start both containers.

```routeros
/container/add file=kingston/fastadhunter-arm64-0.4.0.tar name=fastadhunter-0.4.0 interface=veth1 root-dir=/kingston/fastadhunter/root-0.4.0 mountlists=fah-config,fah-data envlists=fah-env workdir=/home/nonroot cpu-list=cpu0,cpu1,cpu2,cpu3 start-on-boot=no logging=yes comment="fastadhunter"
/container/print
```

Wait until the `E` flag is gone. If the add is refused because `veth1` is in use,
run the first two lines of chapter 5, then this add.

## 5. Swap the containers (router)

Nothing on the LAN resolves between the stop and the start.

```routeros
/container/stop [find name="fastadhunter-0.3.4"]
/container/set [find name="fastadhunter-0.3.4"] start-on-boot=no
/container/set [find name="fastadhunter-0.4.0"] start-on-boot=yes
/container/start [find name="fastadhunter-0.4.0"]
```

## 6. Check the listeners (router, then dev box)

```routeros
/ip/service/print where name="fastadhunter"
/log/print where message~"listener"
/log/print where message~"DoT serves"
```

Expect 53 tcp+udp, 853, 8080, 8443, 8444, and `DoT serves the API certificate`.

```powershell
curl.exe -sk https://fah-api.localbox.ro:8443/health
'' | openssl s_client -connect 172.17.0.2:8444 -servername example.com -brief -CAstore 'org.openssl.winstore://'
```

Expect `"version":"0.4.0"`, then `Peer certificate: CN=example.com` and
`Verification: OK`. If anything differs, stop here. Do not touch the firewall.

## 7. Reject QUIC (router)

Browsers fall back to TCP at once, so HTTPS reaches the SNI filter.

```routeros
/ip/firewall/filter/add chain=forward action=reject reject-with=icmp-admin-prohibited protocol=udp dst-port=443 in-interface=BRIDGE out-interface-list=WAN place-before=[find comment="FastTrack"] comment="fastadhunter: no QUIC, force TCP"
/ipv6/firewall/filter/add chain=forward action=reject reject-with=icmp-admin-prohibited protocol=udp dst-port=443 in-interface=BRIDGE out-interface-list=WAN place-before=[find comment="fasttrack IPv6"] comment="fastadhunter v6: no QUIC, force TCP"
```

If the v6 line refuses `reject-with`, use `action=drop` instead.

## 8. Steer 443 to the container (router)

Run in this order. The accepts must be in before the dst-nat.

```routeros
/ip/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 dst-address-list=fah-http-skip comment="fastadhunter https: leave local traffic alone"
/ipv6/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 dst-address-list=fah-http-skip6 comment="fastadhunter https v6: leave local traffic alone"
/ipv6/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 dst-address-list=fah-lan6 comment="fastadhunter https v6: leave the delegated LAN prefix alone"
/ip/firewall/nat/add chain=dstnat action=dst-nat protocol=tcp dst-port=443 in-interface-list=LAN src-address=!172.17.0.0/24 to-addresses=172.17.0.2 to-ports=8444 comment="fastadhunter https"
/ipv6/firewall/nat/add chain=dstnat action=dst-nat protocol=tcp dst-port=443 in-interface=BRIDGE dst-address=!fd6c:7f32:8e91:1::2/128 to-address=fd6c:7f32:8e91:1::2/128 to-ports=8444 comment="fastadhunter https v6"
```

## 9. Verify (dev box, then router)

```powershell
$key = (ssh bobdenaut ':put [/file/get kingston/fastadhunter/config/apikey contents]').Trim()
curl.exe -sk -H "Authorization: Bearer $key" https://fah-api.localbox.ro:8443/api/v1/config
nslookup doubleclick.net 172.17.0.2
'' | openssl s_client -connect 172.17.0.2:853 -servername fah-dot.localbox.ro -brief -CAstore 'org.openssl.winstore://'
curl.exe -sk -H 'accept: application/dns-message' 'https://fah-api.localbox.ro:8443/dns-query?dns=AAABAAABAAAAAAAAB2V4YW1wbGUDY29tAAABAAE' --output "$env:TEMP\doh-a.bin"
Format-Hex "$env:TEMP\doh-a.bin" | Select-Object -First 3
'' | openssl s_client -connect example.com:443 -servername example.com -brief -CAstore 'org.openssl.winstore://'
curl.exe -s -o NUL -w "http=%{http_code}`n" https://example.com/
```

Expect: config shows `mode = "dns+http+https"`, `dot_enabled = true`,
`doh_enabled = true`, `port = 8444`; doubleclick is blocked; DoT says
`Verification: OK`; the DoH hex starts with `8180` at byte 2; example.com says
`Verification: OK` and `http=200`.

```routeros
/ip/firewall/nat/print stats where comment="fastadhunter https"
/ipv6/firewall/nat/print stats where comment="fastadhunter https v6"
```

Both counters must be non-zero after a browser has been used.

## 10. Phone

Android Private DNS hostname: `fah-dot.localbox.ro`. Works on the home network
only.

## 11. Optional — AAAA records at Cloudflare

Only IPv6-only clients need these. Add after 0.4.0 is running.

```text
AAAA  fah-dot.localbox.ro  →  fd6c:7f32:8e91:1::2
AAAA  fah-api.localbox.ro  →  fd6c:7f32:8e91:1::2
```

## 12. Optional — port-80 v6 rule (router)

Not needed for 0.4.0. Stops the container's own v6 port-80 fetches being steered
back into itself.

```routeros
/ipv6/firewall/nat/set [find comment="fastadhunter http v6"] !in-interface-list in-interface=BRIDGE
```

## 13. Optional — block external DoT (router)

Not needed for 0.4.0. Closes the last encrypted-DNS bypass.

```routeros
/ip/firewall/filter/add chain=forward action=reject reject-with=icmp-admin-prohibited protocol=tcp src-address=192.168.10.0/24 out-interface-list=WAN dst-port=853 place-before=[find comment="FastTrack"] comment="fastadhunter: no external DoT"
/ipv6/firewall/filter/add chain=forward action=reject reject-with=icmp-admin-prohibited protocol=tcp in-interface=BRIDGE out-interface-list=WAN dst-port=853 place-before=[find comment="fasttrack IPv6"] comment="fastadhunter v6: no external DoT"
```

## If a device goes quiet after the deploy (router)

Some IoT and Apple devices open 443 with no SNI and get closed. Take the device
out of the steer, no container restart:

```routeros
/ip/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 src-address=192.168.10.NN place-before=[find comment="fastadhunter https"] comment="fastadhunter https: exempt <device>"
/ipv6/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 src-mac-address=XX:XX:XX:XX:XX:XX place-before=[find comment="fastadhunter https v6"] comment="fastadhunter https v6: exempt <device>"
```

/ipv6/firewall/nat/add chain=dstnat action=accept protocol=tcp dst-port=443 src-mac-address=B8:2C:A0:0F:83:31 place-before=[find comment="fastadhunter https v6"] comment="fastadhunter https v6: exempt heating gateway"

## Rollback (router, dev box, router)

The old TOML must be back in place before 0.3.4 starts: 0.3.4 rejects the
`dot_*`, `doh_enabled` and `[https]` keys and exits, and nothing resolves until
it is started again with a config it accepts.

```routeros
/ip/firewall/nat/remove [find comment~"fastadhunter https"]
/ipv6/firewall/nat/remove [find comment~"fastadhunter https"]
/ip/firewall/filter/remove [find comment~"fastadhunter: no QUIC"]
/ipv6/firewall/filter/remove [find comment~"fastadhunter v6: no QUIC"]
/ip/firewall/filter/remove [find comment~"fastadhunter: no external DoT"]
/ipv6/firewall/filter/remove [find comment~"fastadhunter v6: no external DoT"]
/ipv6/firewall/nat/set [find comment="fastadhunter http v6"] !in-interface in-interface-list=LAN
/container/stop [find name="fastadhunter-0.4.0"]
/container/set [find name="fastadhunter-0.4.0"] start-on-boot=no
/container/print
```

Wait until the 0.4.0 line shows no `R` flag. Both containers use `veth1`, so a
start issued while the other is still stopping is refused. Then, from the
directory chapter 3 ran in:

```powershell
scp fastadhunter.toml.0.3.4 bobdenaut:kingston/fastadhunter/config/fastadhunter.toml
```

```routeros
/container/set [find name="fastadhunter-0.3.4"] start-on-boot=yes
/container/start [find name="fastadhunter-0.3.4"]
```

Phones set to Private DNS in chapter 10 go back to automatic: 0.3.4 has no
DoT and Android's hostname mode does not fall back. The AAAA records from
chapter 11 can stay.
