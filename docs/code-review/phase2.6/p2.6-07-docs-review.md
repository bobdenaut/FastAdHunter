### Findings

**F1 — Major — FIXED — `penalty_round` "returns to 1" describes a value the field never takes**

The field is published verbatim from the packed word (`mod.rs:223`) and every
recovery transition preserves it — `(Penalized|Probing, Success)` packs
`w.penalty_round` (`health.rs:246`), as does `(Healthy, Success)`
(`health.rs:240`). The 300 s rule lives in `next_round` (`health.rs:178-184`)
and decides the round the **next** penalty starts at; it never writes the word.
An endpoint that recovered an hour ago still publishes `penalty_round: 4`.
Impact: the bullet list's own point — `state` is liveness, the rest is
diagnostic — undone by a field read as an active backoff. Evidence: read from
code. **Fix:** API.md now says "the doubling exponent of the last penalty
applied, not an active state … never cleared by recovery"; CONTEXT.md §Penalty
Round rewritten the same way.

**F2 — Should-fix — FIXED — the half-hour-outage run length was wrong, and the two documents disagreed**

API.md said "a run of 5", measurement-traps "~6". At the defaults the run is
≈10: two failures penalize (`health.rs:252-260`), then probes fall at
t ≈ 24, 72, 168, 360, 660, 960, 1260, 1560 s — the ladder is 24/48/96/192 s
before the 300 s cap, so eight probes fit inside 1800 s, each adding one
(`(Probing, Failure)` → `penalize`, `health.rs:281-286`). Both numbers divided
1800 by 300 and dropped the short rounds and the opening failures. Impact
bounded — `run_bucket` clamps at 4 (`mod.rs:555-557`) — but p2.6-11 will read
the conversion. Evidence: derived from the ladder, not measured. **Fix:** the
arithmetic lives once, in measurement-traps, at ≈10 with the `>= 4`-bucket
caveat; API.md links to it and states no number.

**F3 — Should-fix — FIXED — the deferral's cost estimate was wrong: `health::Policy` is public API**

§Deferred claimed the type is not re-exported. `fah-dns/src/lib.rs:24-27` does
re-export it, so both `Policy` names are public today — the collision at its
worst — and the p2.6-12 rename changes `fah-dns`'s public surface. **Fix:**
§Deferred above corrected; the two call sites and the "mechanical" assessment
stand.

**F4 — Minor — FIXED — the `family` rule was wrong for a DoH URL with a literal-IP host**

`url::Host::Ipv4/Ipv6` map to `Some(V4)`/`Some(V6)` (`mod.rs:461-466`); only
`url::Host::Domain` yields `None` (`mod.rs:460`). The "hostname resolved at
connect time" clause cannot occur outside DoH either — a `udp`/`dot` `address`
must parse as an IP or `IP:port` or load fails (`mod.rs:535-546`). **Fix:**
`null` only for a DoH URL with a domain host; `udp`/`dot` rows never `null`.

**F5 — Minor — FIXED — "freezes while penalized, because nothing attempts it" was contradicted three paragraphs above**

`(Penalized, HardFailure | PathFailure)` increments the streak
(`health.rs:270-281`), and a penalized endpoint is attempted whenever no other
candidate exists (`Selected::Forced`), which the `/health` paragraph states.
The case where the reason matters is the one where it is false: total outage,
forced use walking the streak to 255. **Fix:** freeze kept, reason replaced by
the forced-attempt exception.

**F6 — Minor — FIXED — the 300 s cap is nominal; the longest skip is 375 s**

`penalty()` applies 75–125 % *after* the cap (`health.rs:165-171`). **Fix:**
CONFIGURATION.md and CONTEXT.md both now say the cap bounds the nominal value
and the jitter lands on the deadline after it — 225–375 s for a capped round.

**F7 — Minor — FIXED — measurement-traps pointed at `penalized_seconds_total` for duration without the caveat**

A traps document that supplies the pointer and drops the caveat rebuilds the
trap it closes. **Fix:** `penalized_seconds_total` gets its own row —
scheduled not elapsed, lower bound when no query probes after the deadline,
upper bound when an in-flight answer restores `healthy` early, flat across two
reads means no new penalty.

**F8 — Nitpick — FIXED — the derived-penalty arithmetic was stated twice in one comment block**

`CONFIGURATION.md` gave "10 x 3 x timeout_ms … capped at 300000 ms" twice
inside the `timeout_ms` comment (principle 4). **Fix:** folded into one
paragraph — derivation, cap, jitter, ladder, then the `timeout_ms = 10000`
degenerate case.

**F9 — Nitpick — DEFERRED — out of scope: a Rust doc comment still says `adaptive` is unimplemented**

`schema/dns/upstreams.rs:62-64`: "Only `fallback` … is implemented today; more
strategies are documented as future work." Shipped since p2.6-01. Not this
task's file — carried in §Deferred for p2.6-12 alongside the `Policy` rename;
hard rule 7 points at deleting the comment rather than rewording it.
