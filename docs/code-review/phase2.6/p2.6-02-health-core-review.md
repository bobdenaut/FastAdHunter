### Decisions

- **`record` moves no plain counter.** `Transition` reports what the caller
  must do (`closed_run`, `penalty_applied`); accrual belongs to the pool
  (C3, plan §Tests G1 #15).
- **The word sits behind `PackedWord`; the six counters stay `pub AtomicU64`**
  and keep `fetch_add` (S1.10). The counters carry no invariant; the word
  does, and a type without arithmetic turns the never-`fetch_add` rule into a
  compile-time guarantee. `store` stays public — p2.6-05 and the bench seed
  states, and a whole-word store has no carry hazard.
- **Penalized + failure at `cf == 255` returns `NoChange`** rather than
  storing an identical word: same observable state, one CAS fewer during a
  total outage.
- **`closed_run` is `None` for an empty run** (`cf == 0` on a
  Penalized/Probing success), so p2.6-05 never buckets a zero-length run.
- **`nominal_penalty` is private**, shared by `penalty()` and `penalize()`;
  the accrued figure is nominal, not jittered (S1.12).

## Findings

**F1 — FIXED — Should-fix — the G1 #11 concurrent test was vacuous; the CAS
retry path ran in no test**

`concurrent_saturated_failures_leave_word_intact` seeded `cf = 255`,
Penalized, so the saturation arm returned `NoChange` for all 8 × 1 000 calls
— no thread ever stored, and `Err(current) => old = current` was unreached.
Phase CLAUDE.md names test #11 as the mitigation for the packed-word key
risk; as written it proved only the no-op path, so a CAS regression under
contention would have passed the suite. Evidence: code reading, gates green.

Fix — two contended tests added, the saturated variant kept as the explicit
`NoChange` case:

| Test | Seed | Asserts | Line |
| --- | --- | --- | --- |
| `contended_stores_never_corrupt_timestamp_or_round` | Healthy, round 9, `cf = 1`, ts 12 345, `penalty_failures = 255`; 8 threads × 1 000 × (failure, success) | state Healthy, round 9, ts 12 345 unchanged, `cf <= 8` | 585 |
| `contended_failures_saturate_exactly_once` | Healthy, round 4, `cf = 250`, ts 777; 8 threads × 1 000 failures | Penalized, `cf == 255`, round 5, deadline in the jitter band — one thread wins the penalizing CAS, the rest retry onto the saturated word | 609 |
| `concurrent_saturated_failures_leave_word_intact` | Penalized, `cf = 255` | word byte-identical: the `NoChange` arm | 563 |

`cf <= 8` is deterministic, not a tolerance: between a thread's failure and
its own success at most 7 other failures interleave, so the penalize arm is
unreachable and the test cannot flake. Confirmed over 5 consecutive runs.

**F2 — FIXED — Minor — the packed word was `pub state: AtomicU64`, re-exported
outside the crate**

Any caller — bench or later pool code — could `fetch_add` the word and carry
into `timestamp_ms`, the exact phase key risk, with only a grep convention
against it. Fix: the `PackedWord` newtype (`health.rs:17-33`). `Health` is
still 64 B; the const assertion is unchanged and still compiles.
