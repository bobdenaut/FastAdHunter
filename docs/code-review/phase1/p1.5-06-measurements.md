# P1.5-06 Measurements — Raw Run Logs

Verbatim on-device measurement logs backing the analysis in
[`p1.5-06-review.md`](p1.5-06-review.md). This file is the raw appendix — no
interpretation here; see the review doc for what it means.

## Setup

- **Device:** RB5009 (4×ARMv8 @ 1.4 GHz), FastAdHunter in a RouterOS container
  on `veth1` / `172.17.0.2`, DNS on `:53`.
- **Path under test:** client → `192.168.10.1:53` (router dstnat) → container →
  FastAdHunter → back. This is the deployed path, so the numbers include
  RouterOS forwarding/NAT/conntrack.
- **Client:** laptop on the LAN (~5 m from the router), `test_aleator.py`
  reporting `procs : 32`.
- **Generator:** [`plan/closed/phase1.5/test_aleator.py`](../../../plan/closed/phase1.5/test_aleator.py),
  `--profile stress`.
- **Date:** 2026-07-24.

Router CPU sampled manually with `/system/resource/cpu/print` (columns:
`CPU LOAD IRQ DISK`) during each run.
