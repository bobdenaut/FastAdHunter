## Implementation changes

New module `crates/fah-dns/src/upstream/health.rs`, `pub` items re-exported
from `fah_dns` so the S1-M bench (an external target) can drive them.

1. **`Health`** — `#[repr(align(64))]`, fields exactly S1.2:
   `state, attempts, failures, penalties, probes, probe_successes, penalized_ms_total`,
   all `AtomicU64`; `const _: () = assert!(size_of::<Health>() == 64);`.
   `Default`/`new()` = Healthy, `timestamp_ms = 0`.
2. **Packed word** — `const` shifts and masks per S1.3: state bits 0–1,
   `penalty_round` 2–5 (cap 15), `consecutive_failures` 6–13 (cap 255),
   `timestamp_ms` 14–63 (50 bits). Pure `fn pack(State, round, failures, ts) -> u64`
   and `fn unpack(u64) -> Word` (a `Copy` struct). `State` enum
   `Healthy = 0, Penalized = 1, Probing = 2`; the bit value 3 is never
   written — `unpack` maps it to `Healthy` (fail-open, spec S1.3) behind a
   `debug_assert!`. `pack` masks `ts` to 50 bits. A deadline **has passed**
   when `deadline <= now` — one comparison, used by the selector (p2.6-03)
   and by every test here.
3. **`Policy`** — `#[derive(Clone, Copy)] pub struct Policy { penalty_failures: u8, penalty_base_ms: u64, penalty_max_ms: u64 }`
   with `Policy::from_timeout(timeout_ms, penalty_failures)` = base
   `10 × attempt_bound_ms` where `attempt_bound_ms = ATTEMPT_LEGS × timeout_ms`
   (the existing `pub const ATTEMPT_LEGS` in `mod.rs:30` is the single
   source; 24 000 ms at the default), max `300_000`. No trait. Jitter ±25 %
   is a fixed rule inside `penalty()`, not a field. The code's `attempt_timeout`
   parameter is the per-leg value; never use that name for the bound.
4. **`Outcome`** — `pub enum Outcome { Success, HardFailure, PathFailure }`.
5. **`fn next_word(word: u64, outcome: Outcome, now_ms: u64, policy: &Policy) -> Transition`**
   — pure, the S1.3 table verbatim:
   - Healthy/Success: if `consecutive_failures == 0` → `Transition::NoChange`
     (M.5); else clear the field.
   - Healthy/Hard: `cf = min(cf + 1, 255)`; if `cf >= penalty_failures` →
     Penalized with `round = next_round(word, now)`, `ts = now + penalty(round, now)`.
   - Healthy/Path: Penalized immediately, same round/deadline rule.
   - Penalized/Success: Healthy, `cf = 0`, `ts = now`, round kept.
   - Penalized/Hard or Path: `cf` saturating +1 **only**; round and `ts`
     unchanged.
   - Probing/Success: Healthy as above.
   - Probing/Hard or Path: Penalized, `cf` saturating +1 (the open run
     extends — spec S1.12), `round = min(round + 1, 15)`,
     `ts = now + penalty(round, now)`; `penalty_applied = Some(nominal)` —
     a probe failure is a penalty (spec S1.3).
   `Transition` carries the new word plus what the caller must do to the plain
   counters: `closed_run: Option<u8>` (previous `cf` when a success clears it
   — feeds `run_buckets` in p2.6-05), `penalty_applied: Option<u64>` (nominal
   ms to add to `penalized_ms_total` and `penalties += 1`; set on every
   transition *into* Penalized — from Healthy and from Probing).
6. **`fn record(health: &Health, outcome, now_ms, policy) -> Transition`** —
   the CAS loop: `load(Relaxed)`, `next_word`, `compare_exchange_weak(old, new, Relaxed, Relaxed)`,
   retry on mismatch; `NoChange` returns without a store. Plain counters
   (`attempts`, `failures`, `penalties`, `probes`, `probe_successes`,
   `penalized_ms_total`) use `fetch_add(.., Relaxed)`. **The packed word is
   never touched by `fetch_add`.**
7. **`fn penalty(round: u8, now_ms: u64, policy) -> u64`** —
   `min(base << (round − 1), max)` for round ≥ 1, jitter from
   `now_ms & 0xFF` mapped linearly to ±25 % (`nominal × (75 + bits × 50 / 255) / 100`).
   `debug_assert!(round >= 1)`: round 0 is a programming error, never a
   runtime state, because `next_round` yields ≥ 1. The jitter is the same
   for two endpoints penalized in the same millisecond — accepted, spec S1.6;
   no per-endpoint salt is added.
8. **`fn next_round(word, now_ms, policy) -> u8`** — the reset rule: if the
   endpoint was Healthy and `now_ms.saturating_sub(healthy_since) >= penalty_max_ms`
   → 1, else `min(round + 1, 15)`. **Saturating, not plain subtraction**:
   threads sample `Instant::now()` independently, so a success recorded by
   another thread can leave `healthy_since > now_ms` here — plain `−` panics
   in debug (a flaky concurrent test) and resets the round in release.
9. **Clock** — `now_ms` is a `u64` parameter everywhere. The pool owns an
   `epoch: Instant` (p2.6-05); this module never calls `Instant::now()`.

No comments in the file (hard rule 7); the spec's commented struct sketch is
not copied literally.

## Tests

Unit tests in `health.rs`, every one parameterized on `Policy`:

- G1 #3: the size assertion is in the module, so `cargo test` compiling is
  the test.
- One test per `next_word` row above, plus: saturation of `cf` at 255 and
  `round` at 15 with no bleed into neighbouring fields; `timestamp_ms` at
  2⁵⁰ − 1 packs and unpacks; `pack(unpack(w)) == w` for a set of words.
- G1 #9: Probing/failure → `cf + 1`, round + 1, new deadline
  `> old deadline`, `penalty_applied == Some(..)`; Probing/success → Healthy.
- G1 #10: `next_round` returns 1 only when `healthy_since` is ≥ `penalty_max`
  behind `now`, otherwise `round + 1`; tested at `penalty_max − 1` and
  `penalty_max`, and with `healthy_since = now + 1` (the concurrent-sampling
  case) → `round + 1`, no panic.
- G1 #11, concurrent half: `std::thread::scope` with N ≥ 8 threads each calling
  `record(HardFailure)` 1 000 times on one `Health` already at `cf = 255`,
  Penalized with a known deadline; assert the word's state bits and
  `timestamp_ms` equal the initial values and `cf == 255`. Sequential half:
  a word at round 15, Penalized, deadline passed; 16 × (claim Probing via
  `pack` → `record(HardFailure)`) leaves `round == 15`, `cf` saturated, state
  bits valid — the Penalized row never touches the round, so round saturation
  is reachable only through the Probing row.
- `unpack` of a word with state bits `3` → `State::Healthy` (release build
  semantics; the `debug_assert` is documented, not tested).
- Deadline comparison: a word with `deadline == now` counts as passed.
- G1 #12: Penalized + Success → Healthy, `cf == 0`, `ts == now`, round kept.
- G1 #13: a word in Healthy (after a stale success) receiving a failure
  yields `cf == 1`, round unchanged, state Healthy (when
  `penalty_failures > 1`).
- G1 #15: `record` on the transition into Penalized returns
  `penalty_applied == Some(nominal)`; the caller's accrual is asserted in
  p2.6-05.
- `penalty()`: doubling per round, cap at max, jitter within ±25 %, round 1 =
  base.
- M.5 property: `record(Success)` on a Healthy word with `cf == 0` performs
  no store (assert via a word whose value is checked before/after, and via
  `Transition::NoChange`).

## Contradictions — resolved by the owner (2026-08-23)

- **C3 — counter placement: split.** `Health` stays exactly the seven
  spec fields, 64 B, and owns hot selection/penalty state plus `attempts`
  and `failures`. `run_buckets` and the plain `consecutive_failures` stay
  on `UpstreamServer` as cold telemetry state: the plain counter is mutated
  only by the `fallback` loop; under `adaptive` the run length comes from
  `Transition::closed_run` and `run_buckets` is written on run close. The
  `fallback` branch's `server.attempts` / `server.failures` become
  `health[i].attempts` / `.failures` — a textual change with identical
  behaviour, test assertions unmodified.
- **C2 — attempt duration: `attempt_bound_ms = ATTEMPT_LEGS × timeout_ms`.**
  Spec S1.6 now defines it; `PENALTY_BASE = 10 × attempt_bound_ms` (24 s at
  the default). Implemented in step 3 above.
- **C6 — comments.** The spec's struct sketch carries `//` comments; hard
  rule 7 forbids them in Rust. Not copied.
- **M1 / M2 / LOW (validation 2026-08-23, accepted):** Probing/failure bumps
  `cf` and counts a penalty (step 5); `next_round` subtracts saturating
  (step 8); `penalty()` asserts `round ≥ 1` (step 7); state value 3 maps to
  Healthy (step 2); "passed" is `<=` (step 2); jitter is admitted to collide
  for same-millisecond penalties (step 7).
