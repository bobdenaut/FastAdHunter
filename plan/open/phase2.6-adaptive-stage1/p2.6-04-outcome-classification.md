# P2.6-04 — Outcome Classification and Health Mode

**Phase:** 2.6 · **Depends on:** p2.6-02, p2.5-04 · **Model:** Opus

## Goal

Every transport result the plain and encrypted transports can produce maps to
exactly one `Outcome` per the S1.4 table, a DNS RCODE is always a success, and
connection lifecycle events never reach health. A `HealthMode` (`Record` |
`Ignore`) exists for `resolve_host` isolation.

## Context

Spec S1.4 (classification table, the forced-attempt path-failure clause,
attacker-triggerable timeout), S1.8 (health mode), S1.17 (invariant: health
reads only attempt outcomes; handshake failure is one, idle-close, reconnect
and slot state are not). p2.5-04 delivered `io::ErrorKind` fidelity through
the encrypted transports and pinned RCODE-is-not-a-failure; build on it, do
not re-derive it.

## Scope

- `fn classify(&Result<Message, Error>) -> Outcome`: any response → success;
  timeout → hard failure; `ENETUNREACH`, `EHOSTUNREACH`, `ECONNREFUSED`, TLS
  handshake or certificate failure → path failure; malformed / ID-mismatched
  datagrams are already ignored inside `plain::query` and surface as timeout.
- Idle-close followed by transparent reconnect and an answer is one attempt
  with outcome success; the reconnect itself produces no outcome.
- TC → TCP retry that succeeds is success.
- `HealthMode { Record, Ignore }` — a parameter of the attempt path, not a
  trait and not a second pool. In `Ignore` no counter moves, no transition
  occurs and no probe is claimed; `p2.6-05` maps it to the selector's plain
  `claim: bool` (`p2.6-03`), which this task does not touch.

## Acceptance criteria

- S1-G1 #5: NXDOMAIN, SERVFAIL, REFUSED each classify as success.
- S1-G1 #14: idle-close → reconnect → answer yields one success and no
  failure outcome.
- One test per S1.4 row, including TLS handshake failure → path failure.
- `Ignore` mode: a failing attempt leaves every `Health` field unchanged.
- Gates green.

## Out of scope

Calling `record`/`select` from `forward` (`p2.6-05`); changing what p2.5-03
and p2.5-04 do on reconnect.
