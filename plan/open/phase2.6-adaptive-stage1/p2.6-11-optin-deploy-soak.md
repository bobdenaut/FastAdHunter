# P2.6-11 — Opt-in Deploy and Soak

**Phase:** 2.6 · **Depends on:** p2.6-06, p2.6-08, p2.6-09, p2.6-10 · **Model:** Opus

## Goal

`adaptive` runs opt-in on the RB5009 for the 7-day soak, and the deployment
tier of the gates — S1-G2 tiers 2–3, S1-G4, S1-G5 — is decided from
on-device evidence and recorded. This task ends `AWAITING SOAK` until the
window closes.

## Context

Spec §Stage 1 acceptance gates (tier table), S1-G2 tier 2 invariants and
tier 3 as frozen by `p2.6-10`, S1-G4 (run-length distribution read as a
`failure_runs` delta over the window, with the concurrency-splitting caveat),
S1-G5 (rejection routes), S1.9 (flattening counters are the feature working),
S1.14 (binary first, config second). docs/routeros-traps.md for every router
fact.

## Scope

- Merge gate check first: S1-G1 #1–#15 green, S1-G2 tier 1 and S1-G3 files
  written. If any is missing, stop.
- Release: version bump, image build, deploy proposal. Opt-in via the
  container env override from `p2.6-01`, not a TOML edit inside the
  container. **Every `/container`, `/ip`, `/system` command is proposed with
  its effect and timing; the owner runs it.**
- Soak, 7 days: the tier 2 invariant table (penalties on a healthy link,
  attempts per forward, `state` never leaving Healthy on a healthy link, SWR
  attempts unchanged between arms, RSS slope over the final third of a 24 h
  window < 2 MB) from `/telemetry` and `/history/perf`.
- Tier 3, if it survived `p2.6-10`: the named metric against the frozen
  threshold, same session as a `fallback` arm.
- S1-G4: `failure_runs` delta over the full window since the p2.5-06 deploy;
  state whether runs of ≥ 2 exist; choose `penalty_failures` from the data
  or state that the window must be extended.
- S1-G5: both rejection routes evaluated and written down.
- Results file: `docs/code-review/phase2.6/p2.6-11-optin-deploy-soak-review.md`,
  rewriting docs/project-state.md only with approval.

## Acceptance criteria

- Deployed build and deploy time recorded; opt-in confirmed via
  `GET /api/v1/config`.
- Each tier 2 invariant stated with its measured value.
- S1-G4 and S1-G5 each carry a decision and the evidence behind it.
- The table cell in the phase `CLAUDE.md` names what flips `AWAITING SOAK`.

## Out of scope

Changing the default (`p2.6-12`); any router change executed by the agent.
