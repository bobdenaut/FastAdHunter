# P2.6-02 — Health Core

**Phase:** 2.6 · **Depends on:** — · **Model:** Opus

## Goal

The per-endpoint health state machine exists as pure logic in `fah-dns`: a
64-byte `Health` struct with one packed atomic word, a plain `Copy` policy
struct, and a transition function that is a pure function of (current word,
outcome, now, policy), applied inside a saturating CAS loop. No I/O, no clock,
no network — every S1.3 row is a unit test.

## Context

Spec S1.2 (endpoint model, the 64 B assertion), S1.3 (state machine,
transition rule, hard invariant), S1.6 (penalty: policy struct, threshold,
backoff, jitter, round reset), S1.10 (concurrency: relaxed loads, CAS loop
with saturation, never `fetch_add` on the packed word), S1.12 (the six plain
counters and nominal accrual of `penalized_ms_total`).

## Scope

- `Health` — `#[repr(align(64))]`, seven `AtomicU64`, `const _: () = assert!(size_of::<Health>() == 64)`.
- Packed word layout exactly as S1.3: state bits 0–1, `penalty_round` 2–5
  (saturating 15), `consecutive_failures` 6–13 (saturating 255),
  `timestamp_ms` 14–63 (`healthy_since` while Healthy, deadline otherwise).
- `Policy { penalty_failures, penalty_base_ms, penalty_max_ms, jitter }` —
  plain `Copy`, no trait, no dispatch; constructed from values, not from
  `Config`, so tests use scaled constants.
- `Outcome` enum: success, hard failure, path failure (S1.4 classes; mapping
  from transport errors is `p2.6-04`).
- `record(&Health, Outcome, now_ms, &Policy)` — the S1.3 transition table as
  one pure `next_word(word, outcome, now, policy)` plus the CAS loop. Rows:
  Healthy/success, Healthy/hard, Healthy/path, **Penalized/success → Healthy
  round kept**, **Penalized/failure → counter only, deadline and round
  unchanged**, Probing/success, **Probing/failure → `consecutive_failures`
  and round both +1, new deadline, counted as a penalty**.
- `penalty(round)` = `min(base << (round − 1), max) ± 25 %` jitter from the
  low 8 bits of `now_ms`; defined for `round ≥ 1` only (`debug_assert`);
  round reset when `now.saturating_sub(healthy_since) >= penalty_max` at the
  moment the next penalty is applied — saturating, because another thread's
  success may have stored a later `now`.
- Packed state value 3 is never written; `unpack` maps it to Healthy behind a
  `debug_assert`. "Deadline passed" is `deadline <= now`.
- Plain counters move with `fetch_add`; `penalized_ms_total` accrues the
  nominal `penalty(round)` when a penalty is applied, including on a probe
  failure.

## Acceptance criteria

- S1-G1 #3 (assertion compiles), #9, #10 (including the `healthy_since > now`
  case), #11 (N threads at `cf = 255`: state bits and `timestamp_ms` intact;
  plus a sequential claim → probe-failure cycle × 16 at round 15 staying 15),
  #12, #13, #15.
- One test per transition-table row, parameterized on `penalty_failures` and
  on scaled penalty constants; changing the shipped default changes no test.
- No `fetch_add` on the packed word anywhere (grep-able: the word is touched
  only through the CAS loop).
- Gates green.

## Out of scope

Selection and probe claim (`p2.6-03`); transport error mapping (`p2.6-04`);
any wiring into `UpstreamPool`.
