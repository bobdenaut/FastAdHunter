## Implementation changes

1. **`fah-model`** (data only, hard rule 2):
   `pub enum UpstreamState { Healthy, Penalized, Probing }` with
   `#[serde(rename_all = "lowercase")]`, `Default = Healthy`;
   `pub enum AddressFamily { V4, V6 }` `#[serde(rename_all = "lowercase")]`.
   `UpstreamSample` gains, all `#[serde(default)]` so persisted pre-2.6 rows
   and the legacy-JSON test still deserialize:
   `state: UpstreamState`, `penalty_round: u8`, `penalties: u64`,
   `penalized_seconds_total: u64`, `probes: u64`, `probe_successes: u64`,
   `family: Option<AddressFamily>`.
2. **`fah-dns` `UpstreamStatus`** gains the same seven; `status()` fills
   them from `Health` (one relaxed load of the word → `state`,
   `penalty_round`; `penalized_ms_total / 1000`; the counters) and `family`
   from the cold endpoint (`SocketAddr` family for udp/dot; for DoH
   `url.host()` IPv4/IPv6 literal → `Some`, domain → `None`). Under
   `fallback` every endpoint reports `Healthy`, zeros, and the plain
   `consecutive_failures`.
3. **`main.rs` mapping**: copy the seven fields.
4. **`adapters.rs` `degraded()`**: under `adaptive`,
   `!status.is_empty() && status.iter().all(|s| s.state == Penalized)`;
   under `fallback` the existing rule. Needs the strategy — read it from the
   config already available in `main.rs` when the adapter is built, or
   expose `UpstreamPool::strategy()`.
5. **Doc comments** on `consecutive_failures` in both structs keep "Not a
   liveness signal" and gain "`state` is; this freezes while Penalized". No
   new comments elsewhere (hard rule 7 applies to new code; editing an
   existing doc comment on a field is the one place it is needed).
6. **Perf-sample persistence**: `UpstreamSample` rides the 60 s perf sample
   through `fah-stats`; seven small integers per endpoint per minute is
   trivial — keep it unless `fah-stats/src/history/perf.rs` shows a cap.

## Tests

- `fah-model`: serialize → the seven fields present with the expected
  names and lowercase enum strings; the existing legacy-JSON test still
  passes; a round-trip with `family: None` omits nothing surprising.
- `fah-dns`: under `adaptive`, penalize one endpoint → `status()` reports
  `penalized`, `penalty_round == 1`, `penalties == 1`,
  `penalized_seconds_total == nominal / 1000`; probe claim → `probes == 1`,
  `attempts` moved; probe failure → `failures` moved and the run is still
  open; probe success → `probe_successes == 1` and the run closes into
  `failure_runs` with the probe counted in its length.
- `fastadhunter`: `degraded()` true when every endpoint is Penalized, false
  with one Healthy or Probing; under `fallback` the old test stays green.
- The `hits + misses == pass + allow` invariant is untouched (no cache
  counter changes here) — state it in the review file.
