# P2.6-06 — Telemetry

**Phase:** 2.6 · **Depends on:** p2.6-05 · **Model:** Opus

## Goal

Endpoint health is observable: `UpstreamStatus` → `fah_model::UpstreamSample`
→ `/api/v1/telemetry` carries `state`, `penalty_round`, `penalties`,
`penalized_seconds_total`, `probes`, `probe_successes` and `family`, and
`/health` reports degraded when every endpoint is Penalized.

## Context

Spec S1.12 (field table, probe and penalty semantics, the two semantic
changes), S1.9 (counters grow more slowly during an outage — the feature
working). Existing pull path: the 10 s poll in `crates/fastadhunter/src/main.rs`;
`/health` degraded logic at `crates/fastadhunter/src/adapters.rs` (currently
"every server has `consecutive_failures > 0`").

## Scope

- `UpstreamSample` gains the seven fields; JSON is additive. `state` is the
  string `healthy` | `penalized` | `probing`, read from the packed word in
  one relaxed load.
- `penalized_seconds_total` is the nominal accrual from `p2.6-02`, exposed
  in seconds; its doc comment says "scheduled unavailability".
- `consecutive_failures` keeps its field and its "not a liveness signal"
  comment — it is now a diagnostic that freezes while Penalized.
- `/health` degraded = every endpoint Penalized (under `fallback` the
  existing rule stays, since no endpoint is ever Penalized there).
- `failure_runs` unchanged in code; a probe is an ordinary attempt for it.
- Perf-sample persistence: ride the 60 s sample only if the marginal bytes
  are trivial, as p2.5-06 did; live-cumulative is sufficient otherwise.

## Acceptance criteria

- Serialization test: new fields present, existing fields and names
  unchanged; the `hits + misses == pass + allow` invariant untouched.
- `/health` test: all endpoints Penalized → degraded; one Healthy → ok.
- A probe claim increments `probes` and `attempts`; a probe failure
  increments `failures` and extends the open run.
- Gates green. No `.md` edited — API.md and measurement-traps.md are
  `p2.6-07`.

## Out of scope

Dashboard, WS event changes, any per-probe ownership field (the 64 B budget
does not permit it — spec S1.12).
