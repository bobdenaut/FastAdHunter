## Implementation changes

In `health.rs` (same module; the selector is a function over `&[Health]`):

1. `pub enum Selected { Healthy, Probe, Forced }` and
   `pub struct Candidate { pub id: u8, pub selected: Selected }`.
2. `pub fn select(health: &[Health], start: usize, now: impl FnOnce() -> u64) -> Option<Candidate>`:
   - Rule 1: scan `start..len`; first word with `State::Healthy` → return
     `Healthy` **without calling `now`**. The healthy path stays clock-free
     (S1.11: no syscalls added; `Instant::now()` is only needed when a
     deadline must be compared).
   - Rule 2: `now` evaluated once; scan again from `start`; for each
     Penalized word with `deadline <= now`, attempt
     `compare_exchange_weak(word, pack(Probing, round, cf, deadline), Relaxed, Relaxed)`;
     on success → `Probe`; on failure reload once and continue the scan (a
     lost race means someone else claimed it — do not retry the claim; M.7
     must not spin).
   - Rule 3: among `start..len`, the Penalized or Probing word with the
     smallest `timestamp_ms` → `Forced`; no store.
   - `None` only when `start >= len`.
3. The function owns no loop over attempts: the caller (p2.6-05) calls
   `select(.., id + 1, ..)` after a failed attempt, which is how the scan
   "continues from the next endpoint" (S1.5).
4. Rule 3 includes `Probing` endpoints: if every endpoint is Penalized or
   Probing, the forced candidate may be one with a probe in flight; that is
   still one packet sent, and it claims nothing.

## Tests

Unit tests in `health.rs`, synthetic `[Health; n]`:

- Boot: 2 and 8 Healthy → `id 0`, `Selected::Healthy`, and the `now` closure
  is never invoked (assert with a flag).
- First Healthy after k Penalized → `id k`.
- G1 #6 unit: all Penalized, deadlines in the future, distinct → the
  smallest deadline's id, `Forced`; every word unchanged afterwards;
  `probes` untouched (the selector never touches counters — assert the
  whole `Health` byte-for-byte equal).
- Due endpoint → `Probe`; the word now reads `Probing` with round and
  deadline preserved.
- G1 #8: `std::thread::scope`, N ≥ 8 threads, one due endpoint, each thread
  calls `select` once; exactly one `Probe`, the rest `Forced` (no other
  endpoint) — and with a second Healthy endpoint present, the rest
  `Healthy` on that id.
- Continuation: `start = 1` skips id 0 even if Healthy; `start = len` → `None`.
- Mixed: `[Penalized future, Probing, Healthy]` → id 2; `[Penalized future, Probing]`
  → the smaller `timestamp_ms` of the two, `Forced`.
