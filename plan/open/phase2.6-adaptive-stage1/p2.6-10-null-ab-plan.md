## Implementation changes

None to the repository's code. Deliverables:

1. **Run plan** in chat: K (≥ 6, propose 8), alternation order A/B/A/B…,
   per-run duration (the L.1 duration), cool-down between runs, what is
   reset between runs (nothing — same binary; counters are differenced).
2. **Command list** for the owner: start the probe-container load
   generator, read telemetry before/after each run, stop. Each command with
   its effect and when it takes effect. No `/container set|add|remove`
   unless the owner already has the probe container; if not, the procedure
   in routeros-traps.md is quoted, not executed.
3. **Analysis** (agent, from the owner's pasted or fetched outputs):
   per-metric N = spread between the A and B label groups relative to the
   pooled mean, with the per-run values; control-arm (`cache_hit` p99)
   drift; attempts-per-forward and SWR attempts as the zero-variance
   candidates; resolution-vs-K from subsets.
4. **Decision**, written to
   `docs/code-review/phase2.6/p2.6-10-null-ab-review.md`: the metric that
   carries tier 3; threshold = `max(2 × N, 5 %)` on it, or tier 3 dropped
   with N stated; whether SWR needs its own arm in p2.6-11.
