# P2.6-09 — Injected-Failure Bench (G3)

**Phase:** 2.6 · **Depends on:** p2.6-05, p2.6-02, p2.6-06 · **Model:** Opus

## Goal

Every S1-G3 scenario passes against `fallback` in the same session, and the
behavioural win is reported as net timeout cost avoided in two rows —
client-visible forwards and SWR refreshes — not as a raw attempt count.

## Context

Spec S1-G3 (scenario table and §Net timeout cost avoided), S1.15 (failure
scenarios), S1.6 policy (scaled constants make "recovery within
`PENALTY_MAX`" benchable in milliseconds), S1.9 (SWR claims most probes).
Benchmark plan: docs/design/adaptive-upstream-selection-benchmarks.md.

## Scope

- Harness: mock endpoints that black-hole (timeout), refuse (`ECONNREFUSED`
  via a closed UDP port on Linux, a closed TCP port for a DoT endpoint on
  every platform — no `unreachable` knob, loopback cannot produce
  `EHOSTUNREACH`), answer after a delay, and flap on a schedule; a scaled
  `Policy` injected through the pool constructor.
- Scenarios: black-holed primary + healthy secondary; refused primary (a
  classification check, not a win); recovery after the endpoint returns with
  the secondary healthy throughout, ending in a ≥ `PENALTY_MAX` healthy tail
  that exercises the round reset; concurrent probe claims; flapping
  endpoint; `resolve_host` against a due endpoint.
- Measure per scenario, both strategies: paying queries (latency ≥ one leg,
  `timeout_ms`) split into **non-probe** and **probe-carrying**, the
  measured time each paid, client p99, and
  `net_avoided = (fallback_paying − adaptive_paying) × attempt_bound_ms −
  failed_probes × attempt_bound_ms` where `adaptive_paying` **excludes**
  probe carriers (they are `failed_probes`; counting them in both subtracts
  each twice), `attempt_bound_ms = ATTEMPT_LEGS × timeout_ms` is the cap
  and the measured figure stands beside it; reported separately for client
  forwards (black hole, recovery) and for SWR refreshes, with the
  cache-hit-adjusted reading. The tax-free share is stated per tested
  `PENALTY_MAX / PENALTY_BASE` ratio, never as one number.
- **State the attempts per query alongside every outage row** (p2.6-05 F10).
  With every endpoint Penalized, `fallback` always attempts N, while
  `adaptive` attempts between 1 and N: `select` returns the earliest-deadline
  endpoint as `Forced`, and the walk resumes at `start = id + 1`, so a pool
  whose earliest deadline sits last in config order sends one packet and
  stops. A `net_avoided` row without the attempt count is unreadable —
  the strategies are not paying for the same number of attempts.
- Results file: `docs/code-review/phase2.6/p2.6-09-injected-failure-bench-review.md`.

## Acceptance criteria

- Black-hole, sequential queries: ≤ `penalty_failures` **non-probe** queries
  pay up to `attempt_bound_ms` (one leg, `timeout_ms`, on these UDP mocks);
  thereafter only probe-carrying queries pay, one per penalty window, counted
  as `failed_probes`; every other query answers at the healthy endpoint's RTT.
- Refused: Penalized after 1 attempt regardless of `penalty_failures`, ≤ 1
  query pays anything — UDP arm on Linux, DoT arm on every platform; the UDP
  arm on Windows is not a result. Excluded from the net-cost rows.
- Healthy control: decided on counts (`penalties == 0`, `attempts` equal,
  `state` Healthy); timing reported, not gated.
- Recovery (sequential, 20 QPS scaled): Healthy within `penalty_max` + 50 ms
  of the endpoint's return with the secondary Healthy throughout; after the
  1.2 P healthy tail the next penalty lands at `penalty_round == 1`.
- Never more than one probe in flight per endpoint (mock outstanding-request
  high-water mark ≤ 1 while Penalized/Probing); never more than one probe
  per query.
- Flapping: `penalty_round` strictly increasing to the cap, `probes` ≤
  penalty windows elapsed, `p99_flapping ≤ 1.1 × p99_black_hole`.
- RCODE isolation: `state` and `consecutive_failures` unchanged end-to-end
  (the state half of S1-G1 #5).
- SWR: `swr.enqueued ≤ stale_keys × ceil(duration / REFRESH_FAILURE_COOLDOWN)`;
  `swr.dropped` reported.
- All dead: no query without a packet; a forced attempt landing on a
  Penalized word leaves deadline and round unchanged.
- `resolve_host` against a due endpoint claims nothing.
- Net timeout cost avoided stated in two rows with the formula's inputs.
- Gates green.

On-device runs (`p2.6-11`); any hedge or RTT measurement.
