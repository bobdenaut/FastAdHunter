# P2.5-09 — Phase Verification

**Phase:** 2.5 · **Depends on:** p2.5-01…08 · **Model:** Opus

## Goal

The phase's claims hold on the device, not just in tests: a dead listener is
caught, a poisoned list is refused, the run-length collection is live, and
nothing regressed.

## Context

Phase precedent (p1.5-07, p2-08): a hardening phase closes with on-device
evidence, because the two headline fixes here (listener death, refresh
poisoning) were precisely failures no dev-box test surfaces. The router
itself is off limits — every RouterOS-side step is proposed as exact
commands the owner runs.

## Scope

- Gates green across the workspace; benches on touched paths within the
  >10 % regression rule (DNS ingest loops, SWR, upstream walk).
- Release built and deployed by the owner; config-migration check first
  (`deny_unknown_fields` — no key removed by this phase, verify).
- **Listener-death drill** (owner runs, commands proposed): kill the DNS
  path inside the container is not possible without exec — instead verify
  the healthcheck end-to-end: healthy container reports healthy; a
  deliberately misconfigured listen port (staging config, not the live
  resolver) reports unhealthy. Document what RouterOS does with an
  unhealthy container (expected: nothing automatic — record it; the gain
  is visibility, netwatch no longer the only signal).
- **Refresh-integrity drill:** point one disposable list at a URL serving
  an HTML page (owner-approved source change); verify the last-good copy
  survives, the API shows the rejection, protection unchanged.
- **Telemetry checks** on `/telemetry`: SERVFAIL-served counter present
  (zero is fine), endpoint attribution on a live forwarded event via the
  WS, run-length buckets present and monotonic across two snapshots.
- Soak sanity: one overnight window — bounded memory unchanged versus the
  0.2.16 lineage (residual-slope method, measurement-traps.md rules).
- Review file `docs/code-review/phase2.5/p2.5-09-phase-verification-review.md`
  records everything; project-state.md rewrite (owner-approved) closes the
  phase.

## Acceptance criteria

- All eight prior tasks DONE; gates green; deployed release serving.
- Both drills passed and recorded with raw evidence.
- Run-length collection confirmed live — the S1-G4 observation window is
  officially open, dated in the review file.
- No memory or latency regression against the 0.2.16 baselines.

Stage 1 gate); moving this phase to closed (owner's call); any Phase 3
