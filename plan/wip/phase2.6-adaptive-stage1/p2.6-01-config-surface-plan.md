## Implementation changes

1. `UpstreamStrategy` gains `#[serde(rename = "adaptive")] Adaptive`;
   `FromStr` accepts `"adaptive"`; its `Err` string becomes
   `"one of: fallback, adaptive"`. Default stays `Fallback`.
2. `DnsUpstreamsConfig` gains `#[serde(default = "default_penalty_failures")] pub penalty_failures: u32`
   (= 2), added to `impl Default`. `u32` keeps `coerce_u32` and
   `validate_range` reusable; the pool narrows to `u8` at construction.
3. `validate`: `validate_range("dns.upstreams.penalty_failures", penalty_failures, 1, 255)`
   and `validate_range("dns.upstreams.timeout_ms", timeout_ms, 1, 10_000)`
   (spec S1.6/S1.13: 0 makes every penalty zero-length, > 10 000 puts
   `PENALTY_BASE` above `PENALTY_MAX`).
4. `MAX_UPSTREAM_SERVERS` → `8` (C1, decided: spec value). The existing test
   `validation_rejects_more_upstreams_than_an_endpoint_index_can_name` builds
   from the constant and passes unmodified; its name is now loose (a `u8`
   names 255) and is left as is — renaming is a test edit for no behaviour.
5. `env.rs`: arm `["dns","upstreams","penalty_failures"] => coerce_u32`.
6. `fah-dns` `with_tls_config`: add `UpstreamStrategy::Adaptive => {}` so
   the match stays exhaustive; no behaviour until p2.6-05.
7. The nine struct literals listed above gain
   `penalty_failures: default_penalty_failures()` — `default_penalty_failures`
   becomes `pub` for that, or each site uses `..Default::default()` where the
   remaining fields already equal the default. One added line per site;
   nothing else in those files moves.

No comments in new Rust code (root CLAUDE.md hard rule 7; the hook rejects
them).

## Contradictions — resolved by the owner (2026-08-23)

- **C1 — endpoint cap: 8.** Spec S1.2 wins over `MAX_UPSTREAM_SERVERS = u8::MAX`.
  A config with 9–255 servers fails validation on the new binary (none
  known; the default has 2). The existing test builds from the constant and
  passes unmodified.
- **Noted:** the `strategy` env override already exists (`env.rs:76`);
  only `penalty_failures` is added.
- **H1 — "touch no other crate" withdrawn.** A public struct gaining a field
  breaks every literal of it; nine sites in three other crates get the one
  added line (step 7). Their assertions and behaviour are unchanged; spec
  S1.14 and S1-G1 #4 say so in those words.
- **`timeout_ms` range (LOW, accepted).** A validated `1..=10_000`; a
  current-release config above 10 s would fail to boot — none is known, the
  default is 800, and p2.6-07 states the range in CONFIGURATION.md.
